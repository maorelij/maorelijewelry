## 🔔 קבלת הזמנות - חשוב להגדיר בהתחלה!

כל הזמנה שלקוחה שולחת באתר מגיעה למייל **maorelijewelry1@outlook.co.il**.

כדי לקבל **התראת פוש מיידית** בנייד בכל פעם שיש הזמנה חדשה (כמו וואטסאפ),
צריך להגדיר את המייל הזה בנייד שלך. זה לוקח 5 דקות חד פעמיות.

### באייפון 🍎

1. הורד את אפליקציית **Outlook** מה-App Store (חינמי, של מיקרוסופט)
2. פתח את האפליקציה
3. לחץ "Add Account" / "הוסף חשבון"
4. הזן: `maorelijewelry1@outlook.co.il` והסיסמה
5. לחץ על תמונת הפרופיל (פינה ימנית למעלה) ← Settings ← תחת חשבון התכשיטים
6. **Notifications** → **All new messages** ✓

מעכשיו בכל פעם שמגיעה הזמנה - תקפוץ התראה רגילה במסך, כמו וואטסאפ.

### באנדרואיד 🤖

1. אפשר להוסיף את החשבון לאפליקציית **Gmail** הרגילה:
   - פתח Gmail → תמונת פרופיל → "הוסף חשבון" → Outlook/Hotmail
   - הזן: `maorelijewelry1@outlook.co.il` והסיסמה
2. או להוריד את אפליקציית **Outlook** הרשמית - ההגדרה שם בדיוק כמו באייפון

### טיפ לסינון מהיר ✨

כדי שהמייל הזה לא יתערבב עם מיילים אחרים, אפשר להגדיר **תיקייה אוטומטית**
או **תווית** שכל הזמנות יגיעו אליה. באוטלוק זה נקרא "Rules":
- Settings → Rules → Add new rule
- "אם הנושא מתחיל ב-`הזמנה:`" → "העבר לתיקייה: הזמנות"

ככה כל הזמנה תהיה במקום אחד מסודר, ועדיין תקבל התראה מיידית.

## ✏️ עריכה בסיסית - שינוי מחיר או תיאור של פריט קיים

נניח שמאור החליטה להעלות מחיר של פריט מ-8₪ ל-10₪. הנה איך:

### צעד 1: הגעה לקובץ הנכון

1. היכנס ל-github.com והתחבר
2. בעמוד הראשי, לחץ על repository בשם **maorelijewelry**
3. תראה רשימת קבצים. לחץ על הקובץ **index.html**

### צעד 2: עריכה

1. למעלה מימין יש אייקון של עיפרון קטן ✏️ - לחץ עליו
2. נפתח עורך טקסט עם הקוד של האפליקציה
3. לחץ Ctrl+F (או Cmd+F במק) לפתיחת חיפוש
4. חפש את שם הפריט שאתה רוצה לערוך, לדוגמה: `מחזיק מפתחות אות מעוצבת`
5. תמצא בלוק כזה:

```javascript
{
  id: 1,
  name: 'מחזיק אות מעוצבת',
  price: 8,
  category: 'keychains',
  image: '01-keychain-cursive.jpeg',
  emoji: '🔑',
  description: 'מחזיק עדין עם אות מעוצבת...'
},
```

6. שנה את המספר אחרי `price:` למחיר החדש (לדוגמה מ-`8` ל-`10`)
7. את הטקסט בתוך `description:` אפשר לשנות באותו אופן (השאר את הגרשיים בודדות)

### צעד 3: שמירה

1. גלול לתחתית הדף
2. תראה תיבה "Commit changes"
3. בשורה הראשונה, כתוב במה שינית, לדוגמה: `שינוי מחיר מחזיק אות`
4. לחץ על הכפתור הירוק **Commit changes**
5. זהו! תוך דקה השינוי יופיע באתר

⚠️ **חשוב:** אל תשנה כלום שלא קשור למחיר/תיאור/שם.
אם בטעות שינית משהו אחר, פשוט סגור את הדף בלי לשמור.

## ➕ הוספת פריט חדש

נניח שמאור הכינה צמיד חדש שצריך להוסיף לקטלוג.

### צעד 1: העלאת התמונה

1. צלם את התכשיט (רצוי על רקע נקי, לבן או שחור)
2. תן לתמונה שם פשוט באנגלית, לדוגמה: `13-bracelet-pink.jpeg`
   (אסור עברית בשם הקובץ! רק אותיות באנגלית, מספרים, ומקפים)
3. ב-GitHub, היכנס ל-repository
4. לחץ על התיקייה **images** (אייקון של תיקייה)
5. למעלה לחץ על **Add file** ← **Upload files**
6. גרור את התמונה לתוך החלון
7. גלול למטה ולחץ **Commit changes**

### צעד 2: הוספת הפריט לקוד

1. חזור לדף הראשי של ה-repository
2. פתח את **index.html** ולחץ על אייקון העיפרון לעריכה
3. חפש את הטקסט: `// 💎 פריטי קטלוג`
4. תראה רשימה של פריטים. תוסיף פריט חדש בסוף הרשימה,
   ממש לפני הסגריים `];`. העתק את הקוד הבא והדבק:

```javascript
{
  id: 13,
  name: 'צמיד חרוזים ורוד',
  price: 7,
  category: 'bracelets',
  image: '13-bracelet-pink.jpeg',
  emoji: '💗',
  description: 'צמיד עדין עם חרוזים ורודים פסטליים.\nמושלם לאביב 🌸'
},
```

5. שנה את הערכים:
   - `id:` - מספר ייחודי. אם הפריט הקודם היה 12, השתמש ב-13
   - `name:` - שם הפריט בעברית (תוך גרשיים בודדות)
   - `price:` - המחיר במספר (בלי ₪)
   - `category:` - הקטגוריה (ראה רשימה למטה)
   - `image:` - שם הקובץ של התמונה שהעלית
   - `emoji:` - אימוג'י שיופיע בעיצוב (לא חובה, אפשר להשאיר)
   - `description:` - תיאור הפריט. `\n` זה מעבר שורה.

### קטגוריות זמינות

| מה לכתוב ב-category | משמעות |
|---|---|
| `keychains` | מחזיקים |
| `bracelets` | צמידי יד |
| `anklets` | צמידי רגל |
| `rings` | טבעות |
| `earrings` | עגילים |
| `necklaces` | שרשראות |
| `sets` | סטים |

### צעד 3: שמירה

1. גלול לתחתית
2. כתוב הודעה כמו: `הוספת פריט חדש - צמיד ורוד`
3. לחץ **Commit changes**
4. תוך דקה הפריט יופיע באתר
